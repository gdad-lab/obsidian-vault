# 1銘柄 + 日経平均 Fourier 試作

## 目的
1銘柄と日経平均の日足を同じ期間で取得し、各終値を計算期間初日の終値で割って無次元化します。無次元系列を5高調波のFourier回帰で平滑化し、銘柄単体と日経平均に対する相対的な強さを確認します。

この版は Phase 1 の最小試作です。

- 1銘柄 + 日経平均
- 日足取得
- `価格 / 計算期間初日の価格` で無次元化
- 5高調波Fourier回帰
- 日経平均との比較
- 売買代金近似値 `(高値 + 安値 + 終値) / 3 × 出来高`
- CSVとPNGを出力
- 売買注文、自動売買、掲示板、AI評価は含めない

## 重要
- このコードは研究・検証用です。投資判断や利益を保証しません。
- `yfinance` はYahoo公式ライブラリではありません。Yahoo! Financeのデータ利用条件を確認し、個人利用の範囲で使ってください。
- Fourier回帰は過去系列を滑らかに表現するもので、将来価格を保証する予測器ではありません。
- 株式分割等を含む比較のため、初期値は `auto_adjust: true` にしています。

## 環境
Python 3.10以上を推奨。

Termux例:

```sh
pkg update
pkg install python git
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Pydroid 3では、同じ `requirements.txt` のライブラリをpipから入れて `python main.py` を実行してください。定期実行はPhase 2でTermux側に追加します。

## 実行

```sh
cp config.example.yaml config.yaml
python main.py --config config.yaml
```

設定を変えずに試す場合の例は `config.example.yaml` にあります。`symbol` を調べたい東証銘柄コードへ変更してください。

## 出力

- `output/analysis.csv`: 日次系列と計算結果
- `output/summary.json`: 最新日の要約
- `output/comparison.png`: 無次元株価、相対強度、売買代金の図

## 現在の判定値
この試作は売買シグナルを出しません。後で閾値を検証できるよう、以下の連続値だけを保存します。

- `stock_fourier_slope`: 銘柄Fourier近似の直近傾き
- `nikkei_fourier_slope`: 日経平均Fourier近似の直近傾き
- `relative_ratio`: 銘柄無次元値 / 日経平均無次元値
- `relative_fourier_slope`: 相対比率Fourier近似の直近傾き
- `turnover_ratio_20d`: 売買代金近似値 / 直近20日中央値
